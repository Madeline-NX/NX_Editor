# NX_Editor

Веб-редактор на основе Logo Material Studio 0.2.9: композиции, вотермарки, стикеры и 3D.

## Запуск

Скачайте репозиторий и откройте `index.html` в современном браузере. Сборка и установка зависимостей не требуются: приложение поставляется одним HTML-файлом со встроенными ресурсами.

Для запуска через локальный HTTP-сервер выполните в папке проекта (требуется Python 3):

```sh
python -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

## Исходный файл

`index.html` — точная копия `Logo_Material_Studio_Web_0_2_9.html`. Код приложения и встроенные ресурсы сохранены без изменений, включая имеющиеся сведения о лицензиях сторонних компонентов.
